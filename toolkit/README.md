# 我的数字工具记录库

记录数字生活中接触的工具与服务，以及之后慢慢积累的使用体验。

## 电话、邮箱、银行卡
- 中国+86，其他国家有机会可以办，另外也可以用SMS接码，主要是平台注册用
- 邮箱，国内常用qq、163，国际可以用gmail、outlook、icloud，另外还有proton
- 银行卡，国有六大行和股份银行比如招商，国际卡有机会可以办，出国用visa或mastercard

## 社交、娱乐、地图
国内平台，常用的qq、微信、微博、小红书、抖音、Bilibili
国际平台，常用的whatsapp、facebook、X、Instagram、Tiktok、Telegram、Youtube
地图，国内高德（不过广告越来越多了），国际Google Map，开车可以用Waze

## 程序开发
OS：熟练使用Win、Mac、Linux，以及必备的浏览器、文本编辑/Office、终端
开发工具：VSCode，其他（Jetbrain全家桶、Qt、Unity、Matlab、ArcGIS、ContextCapture）
Vibe：Chatgpt/Codex，其他（claude、gemini、grok）
分享平台：Github
